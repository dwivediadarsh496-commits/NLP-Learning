# NLP Learning & Machine Learning Lab Work

A collection of Natural Language Processing (NLP) and Machine Learning practice notebooks, lab assignments, and data preprocessing tasks.

## 📂 Contents

- `06_NLP.ipynb` - Natural Language Processing foundations and exercises.
- `07_NLP_Minor.ipynb` - NLP minor project / exploratory notebook.
- `word_tokens.ipynb` - Tokenization and text processing implementations.
- `03-hierachial-clustering.ipynb` - Hierarchical clustering analysis and customer segmentation.
- `customer_segmentation_data.csv` - Dataset used for clustering and segmentation analysis.
- `DataPreProcessing.ipynb` - Data cleaning, feature scaling, and preparation pipelines.
- `task.ipynb` - Practical problem solving and lab tasks.
